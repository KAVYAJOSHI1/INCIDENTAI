# UI Redesign Specification & Product Guidelines

You are a Senior Product Designer at Stripe and Linear.

Do NOT change any backend logic.

Do NOT modify any API.

Do NOT remove any feature.

Your only task is to redesign the UI.

The current UI looks AI-generated.

Transform it into a modern enterprise SaaS dashboard.

## Requirements:

- Replace the floating horizontal navigation with a permanent left sidebar (250–280px wide).
- Add a clean top header with search, notifications, user profile, and theme toggle.
- Use a white/light professional theme with subtle blue accents.
- Remove neon colors, heavy glows, oversized gradients, and excessive shadows.
- Use a consistent 12-column grid.
- Ensure every page has the same layout and spacing.
- Use Inter font.
- Standardize paddings, margins, card sizes, and typography.
- Make all tables, charts, filters, and forms align consistently.
- Use enterprise dashboard patterns similar to Stripe, Linear, GitHub, Atlassian, and ServiceNow.
- Keep all existing functionality exactly the same.
- Only improve layout, spacing, hierarchy, colors, navigation, and responsiveness.

The final result should not look AI-generated. It should look like a polished B2B SaaS product that an enterprise would confidently purchase.
